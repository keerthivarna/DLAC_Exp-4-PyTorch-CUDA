# DLAC Experiment 4 – PyTorch CUDA

## Aim
To create and manage a deep learning project repository using Git and GitHub, and configure a PyTorch-CUDA development environment for GPU-accelerated applications.

## Technologies Used
- Python
- Git and GitHub
- PyTorch
- CUDA
- Kaggle GPU

## Project Structure
- dataset/
- models/
- notebooks/
- results/
- train.py
- inference.py
- requirements.txt

## Experiment
This project demonstrates Git version control, GitHub repository management, PyTorch tensor operations, and GPU availability verification.
